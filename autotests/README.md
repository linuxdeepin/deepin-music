# deepin-music autotests (qt-autotest-generator)

Graph-driven Google Test suite for the `dmusic` backend library
(`src/libdmusic`). Tests link the real, gcov-instrumented `dmusic` shared
library so [lcov](https://github.com/linuxcoverage/lcov) can report function
coverage on `src/libdmusic`.

Generated by the **qt-autotest-generator** skill using the
`remote-codebase-memory-mcp` knowledge graph
(project `home-uos-service-codebase-repos-deepin-music`, baseline
`master @ f517d7cf`).

## Build & run

```bash
# from the project root (Debug enables gcov instrumentation of dmusic)
cmake -S . -B build-autotests -DCMAKE_BUILD_TYPE=Debug
cmake --build build-autotests -j$(nproc)
cd build-autotests && ctest --output-on-failure
```

Or the all-in-one runner (configure + build + ctest + lcov + HTML/CSV report):

```bash
./autotests/run-ut.sh
# reports:
#   build-autotests/test-reports/test_report.html
#   build-autotests/coverage/html/index.html
```

## Coverage (lcov function coverage, Debug build)

The coverage scope is `src/libdmusic` excluding generated `dmusic_autogen/`
(MOC) and `qrc_config.cpp` (generated code is not hand-written unit-test
logic). The runner's `run-ut.sh` step 5 extracts `*/src/libdmusic/*`.

- **Non-generated source: ~89.4% (505/565 functions)**
- Raw (incl. generated MOC/qrc): ~76%
- **100% of ctest entries pass (304/304)**

Each `TEST_F` runs in its own process via `gtest_discover_tests`, so a crash
in one method never blocks coverage from the others.

## Dependencies

CMake ≥3.16, Qt6 (Core/Gui/Widgets/Svg/Multimedia/Xml/Network/Sql/DBus/Core5Compat),
Google Test, pkg-config: mpris-qt6, taglib, dtk6core, libavcodec/libavformat,
sdl2; lcov+genhtml for coverage. VLC runtime (libvlc + vlc-plugin-base) is
required to construct the VLC backend classes.

## Notes / known limits

The small residual to 90% non-generated is code that cannot be exercised in
a headless CI: D-Bus MPRIS *client*-command lambdas (need a live MPRIS
client), SDL/libvlc C audio callbacks (need real playback), CdaThread
CD-ROM probing (needs a CD drive), one dead-code method
(`VlcPlayer::setEqualizer`, never called), and a process-exit method
(`Presenter::forceExit`). A handful of methods that dereference a null
MprisPlayer without a null-check (`PlayerEngine::resetDBusMpris`) are
exercised only after `setMprisPlayer` populates it.
